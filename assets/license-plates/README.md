# License Plate Assets

The game uses Wikimedia Commons images where a current or still-common standard plate image is available. Alabama, Idaho, and Wyoming use official sample images downloaded from the issuing agencies. Verify the individual file license before redistribution or replacing an asset.

The state boundary file is derived from the PublicaMundi MappingAPI `us-states.json` dataset and is filtered to the 50 states at runtime. District of Columbia and Puerto Rico are intentionally excluded.
