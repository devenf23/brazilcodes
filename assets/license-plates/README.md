# License Plate Assets

The game uses Wikimedia Commons images where a current standard plate image is available. Each image URL and its originating file page are recorded in the game catalog. Verify the individual file license before redistribution or replacing an asset.

The state boundary file is derived from the PublicaMundi MappingAPI `us-states.json` dataset and is filtered to the 50 states at runtime. District of Columbia and Puerto Rico are intentionally excluded.
